# 家庭管家 Wiki 维护约定

适用于 `记忆/`。沿用项目根目录关于用户档案、助手设定和隐私的约定。目录与搭建步骤见 [家庭管家 Wiki 构建指南](家庭管家Wiki构建指南.md)。

- 从 `wiki/index.md` 进入最相关的主题。用户明确要求查知识库时，可用 `scripts/qmd search "关键词" -c meowvis-wiki` 辅助定位，再读原页。通用问题无需查阅家庭资料。
- 用户提供资料时按请求记录。原件由用户管理，保存在 `raw/`。Agent 可以只读查阅相关原件。记录有依据时写来源链接或确认日期。作息、地址、健康和待办状态以用户最新明确说明为准。
- 同一事实放到最相关的主题。其他主题确有需要时链接过去。到期事项在 `wiki/待办与维护.md` 汇总，链接回记录。
- `wiki/管家记忆/` 只保存用户确认的长期偏好、提醒方式和跨主题约定。单次表达、推测和待确认印象不能当成事实。敏感内容按上级约定处理，只使用当前任务所需的片段。
- 按用户要求修改或删除时，检查引用及搜索索引。维护记录只写操作和日期。编辑后运行 `python3 scripts/lint.py` 和 `scripts/qmd update`。
- 每个主题从入口页开始。现有页面足够时沿用；内容过长时再拆分并更新入口链接。记录模板和报告放在 `wiki/维护/`。
- 目前知识库通过人工整理维护。对话采集、候选提炼、印象生成和跨会话自动召回需要后续独立实现。
